# CLAUDE.md — правила работы с этим репозиторием

`PROJECT_SPEC.md` является главным функциональным ТЗ проекта.

Перед выполнением любой крупной задачи обязательно изучай:
- `CLAUDE.md` (этот файл)
- `PROJECT_SPEC.md`
- README.md — практические шаги установки/подключения для пользователя
- соответствующие документы из `/docs`, если они появятся

Не нарушай архитектурные ограничения `PROJECT_SPEC.md` — особенно:
- никогда не вводить и не использовать API-ключи/токены пользователя самому;
- код в репозиторий — только через GitHub "Upload files", никогда через
  встроенный веб-редактор;
- любой новый/изменённый Python-файл — проверить локально
  (`py_compile` + `--demo`) до загрузки в репозиторий;
- себестоимость — только через `data/costs.json`, вручную, без формы на сайте
  и без автоматического заполнения из API.

Если задача противоречит `PROJECT_SPEC.md` или расширяет его рамки — сначала
свериться с пользователем, а не менять архитектуру втихую.
