# Панель Ozon

Личный дашборд по кабинету Ozon: заказы и выручка за последние 7 дней, товары
с риском нехватки остатков, и короткий список конкретных задач на сегодня.
Обновляется сам, каждое утро, без вашего участия. При критичных задачах —
дополнительно присылает уведомление в Telegram.

Как это работает: раз в сутки GitHub Actions запускает `scripts/fetch_ozon.py`,
скрипт заходит в Ozon Seller API, пересчитывает цифры и пересобирает
`index.html`, который показывает GitHub Pages.

## Установка (один раз)

### 1. Создайте репозиторий

На github.com → New repository → назовите, например, `ozon-panel` → Create.
Загрузите туда все файлы из этой папки (кнопка **Add file → Upload files**,
можно просто перетащить всё мышкой) и нажмите **Commit changes**.

### 2. Добавьте ключи Ozon как Secrets

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.

Добавьте два секрета:
- `OZON_CLIENT_ID` — Client-Id из личного кабинета продавца Ozon (Настройки → Seller API)
- `OZON_API_KEY` — соответствующий Api-Key

Эти значения нигде не показываются в интерфейсе после сохранения — это безопасное место.

### 3. Включите GitHub Pages

**Settings → Pages** → в разделе Source выберите **Deploy from a branch**,
ветка **main**, папка **/ (root)** → Save.

Через минуту-две сайт появится по адресу:
`https://yulyakudryavtseva1-ctrl.github.io/ozon-panel1/`
(вместо имени подставьте то, что получилось у вас).

Важно: бесплатный GitHub Pages работает только с публичными репозиториями —
если ваш репозиторий приватный, либо сделайте его публичным (Settings →
Danger Zone → Change visibility), либо оформите платный GitHub Pro. Публичный
репозиторий значит, что код и сама страница видны всем, у кого есть ссылка
(но нигде не публикуется и не индексируется сама по себе).

### 4. Запустите первое обновление вручную

**Actions** (вкладка вверху репозитория) → слева выберите workflow
**«Обновление панели Ozon»** → справа кнопка **Run workflow** → Run workflow.

Через 1-2 минуты обновите страницу сайта — на ней должны появиться ваши
реальные цифры. Дальше это будет происходить само каждое утро в 9:00 МСК.

## Уведомления в Telegram (опционально, но рекомендуется)

Если на сайте появляется что-то критичное (остаток товара вот-вот кончится,
резкий провал заказов) — бот сам напишет вам в Telegram, не нужно каждый день
открывать сайт, чтобы это заметить. Если секреты ниже не настроены — сайт
всё равно работает как обычно, просто без уведомлений.

### Создать бота (2 минуты, в самом Telegram)

1. Откройте в Telegram чат **@BotFather** → отправьте `/newbot`.
2. Придумайте имя (любое) и username бота (должен заканчиваться на `bot`,
   например `yulya_ozon_bot`).
3. BotFather пришлёт **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   — это и есть `TELEGRAM_BOT_TOKEN`. Никому его не показывайте, кроме поля
   Secret на GitHub (см. ниже).
4. Напишите вашему новому боту любое сообщение (например «привет») — иначе
   он не сможет писать вам первым.
5. Откройте в браузере (замените TOKEN на ваш токен):
   `https://api.telegram.org/botTOKEN/getUpdates`
   В ответе найдите `"chat":{"id":123456789,...}` — это число и есть
   `TELEGRAM_CHAT_ID`.

### Добавить как Secrets

Так же, как с ключами Ozon: **Settings → Secrets and variables → Actions →
New repository secret**.

- `TELEGRAM_BOT_TOKEN` — токен от BotFather
- `TELEGRAM_CHAT_ID` — число из getUpdates

Уведомление придёт только если есть критичные/требующие внимания задачи —
бот не будет писать вам каждый день просто чтобы отчитаться.

## Реклама и ДРР (опционально)

Это отдельный от Seller API кабинет — Ozon Performance API, со своими
ключами. Без него блок "Реклама и ДРР" остаётся заглушкой "скоро" и
ничего не ломает.

### Получить ключи

1. В личном кабинете Ozon: **Настройки → API-ключи → Performance API →
   Добавить ключ**.
2. Скопируйте оба значения: **Client ID** и **Client Secret**. Это не те же
   самые ключи, что `OZON_CLIENT_ID`/`OZON_API_KEY` из первого шага —
   отдельная пара, специально для рекламного кабинета.

### Добавить как Secrets

Так же, как остальные: **Settings → Secrets and variables → Actions →
New repository secret**.

- `OZON_PERFORMANCE_CLIENT_ID`
- `OZON_PERFORMANCE_CLIENT_SECRET`

**Честно предупреждаю:** в отличие от остальных методов в этом проекте, вызовы
Performance API в `scripts/fetch_ozon.py` собраны по открытым описаниям, а не
проверены вживую (у самой площадки это менее задокументировано, чем основной
Seller API). Если после добавления ключей карточка "Реклама и ДРР" покажет
"не удалось получить данные" — откройте **Actions → последний запуск → шаг
"Получить данные Ozon и пересобрать страницу"**, скопируйте текст ошибки и
пришлите мне, поправим путь/параметры по факту — так же, как чинили остатки
в первый раз. Это не критичный блок: даже если он не заработает с первого
раза, вся остальная страница (заказы, остатки, задачи) продолжит работать.

## Еженедельный ИИ-разбор

Отдельно от ежедневного обновления цифр, раз в неделю запускается разбор от
Claude: не просто цифры, а что они значат и что с этим делать. Результат
сохраняется в проект Claude — там же, где хранятся остальные заметки по
этому кабинету, — и приходит вам как уведомление.

## Если что-то пошло не так при первом запуске

Откройте **Actions → «Обновление панели Ozon» → последний запуск**, разверните
шаг «Забрать данные Ozon и пересобрать страницу» — там будет текст ошибки.
Чаще всего это означает, что у конкретного метода Ozon API изменилось имя
поля или путь — сверьтесь с https://docs.ozon.ru/api/seller/ (открывайте
только этот официальный домен) и пришлите мне текст ошибки, поправим.

Сайт устроен так, что одна неудачная попытка не сломает уже работающую
страницу — при ошибке используются данные последнего успешного запуска.

Если Ozon вернул `429 Too Many Requests` — это не баг, а лимит частоты
запросов, обычно после нескольких ручных перезапусков подряд. Подождите
15–30 минут и попробуйте снова.

## Посмотреть, как это выглядит, без реального ключа

Локально (или попросите меня показать): `python scripts/fetch_ozon.py --demo`
соберёт `index.html` на синтетических примерах, ничего не запрашивая у Ozon.

## Подключить свой домен позже

**Settings → Pages → Custom domain** — впишите купленный домен и настройте
у регистратора домена DNS-запись по инструкции, которую покажет GitHub.
