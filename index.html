Как это устроено

Каждое утро робот (GitHub Actions) заходит в API Ozon и Wildberries, пересчитывает цифры по каждому кабинету и публикует обновлённую версию этой страницы. Чистая прибыль считается по себестоимости из data/costs.json — заполняете сами, по мере добавления товаров. Если появляются критичные задачи — параллельно уходит уведомление в Telegram. Раз в неделю отдельный ИИ-разбор дополняет цифры выводами и рекомендациями. Один кабинет может временно не отвечать — это не ломает данные по другому.
